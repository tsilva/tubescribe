# TubeScribe Skills

For a newsletter or digest of followed channels, use [tubescribe_newsletter](.agents/skills/tubescribe_newsletter/SKILL.md). Group summaries by channel, with each video summarized separately within its channel. It uses saved summaries only and defaults to videos published in the last seven days. Keep this skill local to this project.

For pipeline smoke tests or end-to-end verification of selected videos, use [tubescribe_verify-pipeline](.agents/skills/tubescribe_verify-pipeline/SKILL.md). Check word timestamps, speaker continuity, saved-result recovery, and live transcript and summary delivery. Keep inspection read-only unless processing or a release is authorized. Keep this skill local to this project.
